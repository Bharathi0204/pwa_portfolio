# 3. Major Projects

## AGRIMISTRO --- IoT Agricultural Telemetry Intelligence Platform

**Achievement:** 1st Prize --- AI & Generative AI, SRM Project Day 2026\
**Award:** ₹50,000

**Stack:** ESP32, IoT sensors, Python, FastAPI, React, Supabase,
OpenAI/GenAI

### Problem

AGRIMISTRO focuses on **water scarcity and limited farming space**.

### Physical prototype

A compact farming setup used: - Water reservoir - Fogger - Coco peat -
Small crop plants - Enclosed growing structure - ESP32

### Sensors

-   Soil moisture
-   Water level
-   Room temperature
-   Humidity
-   pH

### Data flow

``` text
Sensors
   ↓
ESP32
   ↓
Real-time telemetry
   ↓
Python / FastAPI
   ↓
Supabase
   ↓
React dashboard
   ↓
AI reasoning
   ↓
Recommendations / alerts
```

### AI layer

The system interprets telemetry and can identify conditions such as low
water, unhealthy moisture/environmental conditions and abnormal pH, then
provide recommendations.

### Multilingual capability

The advisory layer supports **22 Indian languages**.

### Notification concept

Important conditions can trigger alerts/email notifications so farmers
do not have to continuously monitor the system.

### Startup vision

The long-term idea is compact vertical farming where multiple growing
units can be stacked in a limited space. The concept is especially
suited to smaller crops, leafy vegetables, herbs, selected vegetables
and other plants appropriate to a controlled growing environment.

### Interview explanation

> AGRIMISTRO started from the problem of water scarcity and limited
> agricultural space. We built a small IoT-based vertical farming
> prototype using coco peat and a fogger-based moisture system. An ESP32
> collected soil moisture, water level, temperature, humidity and pH
> data in real time. That telemetry was sent into the software layer,
> visualized through React, and used by an AI layer to generate
> recommendations. We also added multilingual support for Indian
> languages. The project won first prize in AI and Generative AI at SRM
> Project Day 2026.

## TaskOS --- AI-Generated Micro Operating System

**Event:** HackForge 2025

**Stack:** Python, Generative AI, Docker, Linux

### Concept

TaskOS explores dynamically creating isolated environments for
individual tasks.

``` text
Task
 ↓
AI determines required environment
 ↓
Docker container created
 ↓
Task executes
 ↓

```

### Why Docker?

Docker provides isolated execution environments so one task can run
without polluting the main environment.
